# OUR OS

OUR OS is an independent Linux distribution project focused on a modern,
familiar desktop experience with a strong cybersecurity and developer focus.

## Current Goal

Build a reproducible bootable Linux ISO.

## Architecture

Windows
    ↓
Source code
    ↓
GitHub
    ↓
GitHub Actions
    ↓
Debian live-build
    ↓
OUR OS ISO
    ↓
VMware
    ↓
Testing

## Version

0.1.0

## Build

ISO builds are currently performed automatically through GitHub Actions.
